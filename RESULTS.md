## 3. Simulated SEU fault injection

Subset: D-2, D-4, E-13, E-7, G-6, M-5, M-7, P-10, P-14, T-13 (5 SMAP + 5 MSL, drawn by seed before any fault result), training seed 0, telemanom detection. Only 13 labeled events, so event F1 moves in steps of about 0.08. Clean event F1 on the subset: INT8 0.615, float32 0.545. 100 Monte Carlo trials per condition.

### 3.1 Persistent weight flips: INT8 is bounded, float32 is not

- float32, 100 flips: 98% of trials produce NaN/inf forecasts; event F1 0.457 (clean 0.545). A NaN poisons the running error average, so the detector goes silent from that point.
- INT8, 100 flips: no non-finite values are possible; 0% catastrophic trials; event F1 0.713.
- **Detection F1 does not track model health.** With the same 100 flips, 44% of INT8 models have more than 2x their clean forecast error on normal data (19% more than 10x), yet event F1 is higher than clean. A damaged forecaster still flags large deviations, which many SMAP/MSL anomalies are. Onboard, model health has to be checked directly (e.g. checksums), not inferred from the detector's output.

### 3.3 Bit position and layer

See `figures/fault_bitpos.png` and `results/faults_summary.json` (`bitpos`). float32 exponent bits (esp. bit 30) and sign bits dominate; for INT8 only the output layer's high bits change forecasts often. Per flipped bit the output layer is the most sensitive, but the input layer holds most of the bits.

### 3.4 Protections

Each protection is compared with its own fault-free F1, because clamp and the sanity check act on every inference.

- INT8, 100 flips: unprotected F1 0.625; highest with `scrub` 0.633 (its fault-free F1 0.615).
- float32, 100 flips: unprotected F1 0.428; highest with `clamp` 0.638 (its fault-free F1 0.640).
- INT8: every protection's mean F1 lies within one trial standard deviation (0.059) of the unprotected value or below it; faults did not break INT8 detection, so there was little to recover. The sanity check lowers F1 even without faults (it also hides real out-of-range anomalies).
- float32: the activation clamp gives the highest F1 but also raises fault-free F1 (bounded outputs help on this benchmark); CRC scrubbing recovers to about the clean level only with verify-then-commit release of outputs (a naive version was worse than no protection, docs/DECISIONS.md #28).

## 4. What this does NOT show

- Radiation behaviour: faults are simulated bit flips in software, uniform over stored bits.
- ESP32 energy: not measured (estimate only); latency was measured for one SMAP-channel model only.
- Generality: one benchmark with known flaws; the fault subset has 13 labeled events.
- Telemanom parity: the port follows telemanom/errors.py but was not run side by side with the original (docs/DECISIONS.md #19).
